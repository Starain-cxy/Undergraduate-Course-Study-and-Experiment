# 本科课程学习与实验

本仓库用于整理本科阶段部分数学、统计、金融与数据科学课程的学习笔记、课程作业、实验代码和项目报告。内容以课程为单位归档，既包含理论推导与复习资料，也包含使用 Python、MATLAB 和 LaTeX 完成的数值实验，因为作者很懒所以很多数据和依赖都没有传上来，大家可以用ai自行检查，补充依赖和数据的路径即可。

想对DHU数统专业有更多了解详见`DHU数统本科通关教程`。

> 本仓库是课程学习成果合集，不是一个统一的软件应用。各实验相互独立，运行代码时请先进入对应代码所在目录。

## 代表性内容

### 非参数统计
任课老师：谢老师

最后考试不需要所有知识点的代码，基本只用`SPSS`即可，所以没写完。

`NonparametricStats/Chapter3` 实现了三类两样本非参数检验：

- Brown–Mood 中位数检验；
- Mood 方差检验；
- Moses 方差检验。

每个脚本顶部均提供样本、备择假设和显著性水平等参数，可直接修改后运行。例如：

```bash
cd NonparametricStats/Chapter3
python Brown_Mood_Median_Test.py
```

### 利息论与计量经济学
任课老师：张老师

该模块包含永续年金现值的数学推导，是*利息论*的一道期末考题，期末不用把这些都写上去可以直接背结果，对这个结果是怎么来的感兴趣的同学可以看下推导过程

Lévy 过程首达概率的离散化分析，是*计量经济学*的大作业

`Numerical solution to the nontrivial bound of the survival probability` 进一步提供了完整的数值实验材料：

1. 使用 `preprocessing.py` 从上证指数数据中计算日对数收益率；
2. 使用 `fit_character.m` 通过经验特征函数拟合对称 α-稳定分布；
3. 使用 `test_bound.m` 和 `etf_bound.m` 计算并绘制首达概率上界。

运行这些脚本时，应将当前目录切换到该实验目录。仓库已经包含 MATLAB 实验所需的 `log_returns.mat`。

### 多元统计分析

`分布趋近正态分布的过程` 是老师布置的小作业通过离散卷积观察标准化样本和的密度逐步接近标准正态分布，并使用 $L^1$ 距离衡量差异。

`总结性大作业` 中保存了聚类分析与判别分析的 LaTeX 源文件，为了方便没有把pdf放进来，其实可以直接复制给ai让他处理。

> 两份 LaTeX 文档引用了 `fig/` 目录中的图片，但相关图片当前未包含在仓库中；如需完整编译，请先补齐对应图片资源。

### 数据挖掘

任课老师：周老师

文件主要包含数据挖掘课程的大作业，这门课大作业比较多样。

- 鸢尾花分类：数据可视化、RBF 核 SVM 分类和 Softmax 回归分类；
- 波士顿房价预测：岭回归、决策树回归、交叉验证与网格搜索；
- PINN 综述：物理信息神经网络相关论文阅读报告。

数据挖掘脚本使用相对于当前目录的数据路径。运行前请将数据文件放入对应的 `code` 目录：

| --- | --- |
| 鸢尾花分类 | `IRIS.csv` |
| 波士顿房价预测 | `boston_housing.csv` |

上述两个 CSV 文件当前未包含在仓库中。

### 随机过程

任课老师：舒老师

主要是随机过程的大作业。

该模块围绕泊松过程展开，包括按时间或事件数截断的样本路径模拟、泊松分布卡方拟合优度检验，以及不相交区间增量的独立性检验。基础模拟入口为：

```bash
cd 随机过程/code
python main.py
```

实验报告见 `随机过程/泊松过程的模拟、分析与验证.docx`。


## 环境与依赖

建议使用 Python 3.9 或更高版本。Python 实验涉及的主要第三方库如下：

```bash
pip install numpy pandas scipy matplotlib seaborn scikit-learn openpyxl
```

SAS 示例需要在 SAS 环境中运行；涉及 Excel 或文本数据的程序还需准备对应数据文件并调整本地路径。MATLAB 实验建议使用较新的 MATLAB 版本，其中稳定分布参数拟合代码使用了 `fmincon`，需要 Optimization Toolbox。LaTeX 作业含中文内容，建议使用 XeLaTeX 编译。

## 使用说明

1. 克隆或下载本仓库；
2. 根据上方内容概览选择课程模块；
3. 阅读对应的 PDF、Word 或 Markdown 文档；
4. 运行实验前进入脚本所在目录，并按需修改脚本顶部的样本或参数；
5. 涉及外部数据或图片的实验，请先按本文说明补齐相应文件。

部分绘图代码指定了 `SimHei` 或 `Microsoft YaHei` 等中文字体。如果图中的中文无法正常显示，请在本机安装对应字体，或修改脚本中的 Matplotlib 字体设置。
